# Desafios Cursos Python

Repositório onde vou guardando os desafios que resolvo enquanto faço os cursos de Python do Curso em Vídeo (professor Gustavo Guanabara).

A ideia aqui não é ter um código perfeito, é registrar o processo de aprendizado e ter um histórico de tudo que já pratiquei.

O que tem aqui:

Os arquivos estão na pasta desafios/, numerados na ordem que fui resolvendo (desafio001.py, desafio002.py...). Cada um é um exercício separado.


Rodando os arquivos

Precisa ter Python 3 instalado. Depois é só rodar:

python desafios/desafio001.py

Troca o número pelo desafio que quiser ver.
